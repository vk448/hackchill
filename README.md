# 🧋 Boba Bash

> **Sip the sweetness. Fear the pearls.** 👁️

Boba Bash is a bubble tea website with a fun personality and a mysterious side. It combines a cozy boba-inspired theme with creepy terminal messages, neon colors, glitch animations, and a hidden *System Hacked* experience.

## ✨ Features

- 🧋 **Boba-Themed Design** — A website inspired by bubble tea and tapioca pearls.
- 💚 **Neon Color Palette** — Dark backgrounds with neon green, cyan, and glitch-red accents.
- 👁️ **Creepy Easter Eggs** — Unexpected messages such as “YOUR BOBA IS WATCHING” and “THE PEARLS ARE AWAKE.”
- ⚡ **Glitch Effects** — Animated overlays and flickering text for a mysterious experience.
- 🌟 **Neon Logo Glow** — A glowing boba logo using CSS filters.
- 💻 **System Hacked Page** — A fictional terminal-inspired screen with eerie messages and warning banners.
- 📱 **Responsive Layout** — CSS designed to adapt to different screen sizes.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

```bash

```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Open the project

Open the project folder in VS Code.

### 3. Run the website

Open `index.html` in your browser, or use the **Live Server** extension in VS Code.
